# Pulseframe / PulseframeOS

## Overview
The world's first biometrically-driven productivity platform.

## Architecture

### Backend (PulseframeOS)
- Node.js/Express
- Python/FastAPI for ML
- C++ algorithms
- PostgreSQL/TimescaleDB
- Docker

### Frontend (AIDA)
- Expo/React Native (mobile)
- Tauri/Rust (desktop)

### AI (Agentic Subsystem)
- Python 3.14+
- OpenAI Agents SDK
- Agents: AnalysisAgent, EventChangeAgent, PatternAgent, CorrelationAgent

## Capabilities
- Stress Detection
- Productivity Scoring
- ML Predictions
- Agentic AI Analysis

## Integrations
- Apple HealthKit
- Google Calendar
- Microsoft Graph (OAuth 2.0)
