\subsubsection{\centering Utilizing Close Analogs to Understand The Difference Equation with Variable Structure}\label{sec:difference-equation-with-variable-structure}% (fold)

The affine in the inputs discrete-time nonlinear dynamic system will be considered.
Both a semantic and mathematical description of the system will be provided.

\begin{definition} Affine-In-The-Inputs Discrete-Time Nonlinear System\textsubscript{[1]}\label{eq:dynamic}
	\begin{equation}
		\begin{aligned}
			\underbrace{x(k+1)}_{\substack{\text{next}                        \\ \text{system-state}}}
			 & = \underbrace{x(k)}_{\substack{\text{current}                  \\ \text{system-state}}}
			+ \underbrace{ \mathlarger{\tau}}_{\substack{\text{discrete-time} \\ \text{step}}}
			\bigl[\underbrace{ f(x(k))}_{\substack{\text{state}               \\ \text{dynamics}}}
			+ \underbrace{ g(x(k))}_{\substack{\text{coupling}                \\ \text{dynamics}}}
			\underbrace{u(k)}_{\substack{\text{control}                       \\ \text{input}}} \bigr]
		\end{aligned}
	\end{equation}
\end{definition}

\begin{description}
	\setlength{\itemsep}{0.35em}
	\item[\makebox[10.5em][l]{Affine-In-The-Inputs:}] The system dynamics can be expressed as the sum of the
	      linear function of the inputs and the nonlinear function of the states.
	      This property simplifies the analysis and control design for such system.
	      The linear function of the inputs is vital as it allows for the solution
	      to be derived analytically.
	\item[\makebox[10.5em][l]{Discrete-Time:}] The system state is updated at specific, uniform intervals of time.
	      The discrete-time dynamic system does not require training.
	      This stands in contrast to continuous-time systems,
	      where one must resort to numerical methods for simulation and analysis.
	\item[\makebox[10.5em][l]{\(f(x)\):}] Nonlinear function that defines the system's internal state dynamics.
	\item[\makebox[10.5em][l]{\(g(x)\):}] Function that defines the effect of the control input on the state dynamics.
	\item[\makebox[10.5em][l]{\(u(k)\):}] Linear function that defines the control input applied to the system.
	\item[\makebox[10.5em][l]{\(\tau\):}] Represents each discrete-time step.
\end{description}
