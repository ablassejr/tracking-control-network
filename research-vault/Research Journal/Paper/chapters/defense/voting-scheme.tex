The adversarial attacks discussed in this paper degrade tracking performance by
perturbing the output of the signal function used in the controller. When
additive noise is injected into the signal function, the defense is based on
rounding the noisy output to the nearest integer value.

Consider the signal function $\operatorname{sgn}(e(k))$ from
\eqref{eq:error_dynamics} subject to additive noise $\epsilon(k)$. The
noisy signal function output is
\begin{equation}
	\label{eq:noisy_sgn}
	\widetilde{s}(k) = \operatorname{sgn}(e(k)) + \epsilon(k),
\end{equation}
where $\epsilon(k)$ is a stochastic perturbation. Since the clean output of
$\operatorname{sgn}$ takes values in $\{-1, 0, +1\}$, the correct value can
be recovered by rounding, provided $|\epsilon(k)| < \tfrac{1}{2}$. The
defended output of the signal function is defined by
\begin{equation}
	\label{eq:rounding_defense}
	\hat{s}(k) =
	\begin{cases}
		+1 & \text{if } \widetilde{s}(k) > +\tfrac{1}{2},  \\[4pt]
		0  & \text{if } |\widetilde{s}(k)| \leq \tfrac{1}{2}, \\[4pt]
		-1 & \text{if } \widetilde{s}(k) < -\tfrac{1}{2}.
	\end{cases}
\end{equation}
When $|\epsilon(k)| < \tfrac{1}{2}$, the rounding operation satisfies
$\hat{s}(k) = \operatorname{sgn}(e(k))$, so that the defended control input
\begin{equation}
	\label{eq:defended_control}
	\hat{u}(k) = g(x(k))^{-1} \bigl( -f(x(k)) + \Delta r(k) - \beta \hat{s}(k) \bigr)
\end{equation}
is identical to the unperturbed control input \eqref{eq:control_function},
and the defended closed-loop state equation
\begin{equation}
	\label{eq:defended_closed_loop}
	x(k+1) = x(k) - \beta \hat{s}(k) + \Delta r(k)
\end{equation}
reduces to the unperturbed system \eqref{eq:closed_loop}.
