\subsection{Voting Scheme Defense}

The defense mechanism employs $n=3$ parallel processing units, each
independently computing the tracking error $e(k)$\eqref{eq:error_dynamics}.
This approach follows the redundant voting paradigm used in
safety-critical systems~\cite{lyons1962tmr, siewiorek1998reliable}.
An adversarial attack corrupts at most one unit by injecting additive noise
into its error computation. This redundancy enables detection and exclusion
of the corrupted processing unit through pairwise comparison.

Consider $n = 3$ processing units computing the tracking error. Unit $i \in [1, i_{max}]$ produces
\begin{equation}
	\label{eq:channel_error}
	e_i(k) = e(k) + \delta_i(k),
\end{equation}
where $i_{max} = n$. $\delta_i(k)$ represents the noise on processing unit $i$.
When clean units are ideal, $\delta_i(k) = 0$, implying $e_i(k) = e(k)$. The pairwise
disagreement between units $i$ and $j \in [1, j_{max}] \text{, where } j_{max}=n \text{, and } j \neq i$ is defined as
\begin{equation}
	\label{eq:pairwise_disagreement}
	V_{ij}(k) = \|e_i(k) - e_{j}(k)\|^2.
\end{equation}
On ideal, clean units, $\delta_i(k) = \delta_j(k) = 0$, so $e_i(k) = e_j(k) = e(k)$, and $V_{ij}(k) = 0$.
The minimum-variance pair is selected by
\begin{equation}
	\label{eq:pair_selection}
	(i^{*}, j^{*}) = \underset{(i,j)}{\arg\min} \; V_{ij}(k).
\end{equation}
The defended error signal is calculated as the average of the selected pair,
\begin{equation}
	\label{eq:defended_error}
	\hat{e}(k) = \frac{e_{i^*}(k) + e_{j^*}(k)}{2}.
\end{equation}
Substituting $\hat{e}(k)$ into the control law\eqref{eq:control_function}
gives the defended control input
\begin{equation}
	\label{eq:defended_control}
	\hat{u}(k) = g(x(k))^{-1} \bigl( -f(x(k)) + \Delta r(k) - \beta \operatorname{sgn}(\hat{e}(k)) \bigr),
\end{equation}
and the defended closed-loop state equation
\begin{equation}
	\label{eq:defended_closed_loop}
	x(k+1) = x(k) - \beta \operatorname{sgn}(\hat{e}(k)) + \Delta r(k).
\end{equation}
