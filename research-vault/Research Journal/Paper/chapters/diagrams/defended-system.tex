The corresponding functional block-diagram of the defended nonlinear system is
presented in Fig.~\ref{fig:defended-system}. The diagram extends the attacked
system (Fig.~\ref{fig:attacked-system}) by adding three parallel processing
units and a voter block $V$. Each processing unit independently computes
the tracking error $e_i(k)$; one unit is
corrupted by the adversarial perturbation. The voter block receives all three
error signals, selects the minimum-variance pair via
(equation), and outputs the defended error $\hat{e}(k)$. The
remainder of the control path is identical
to the nominal system in Fig.~\ref{fig:clean-system}.
