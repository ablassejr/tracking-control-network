The corresponding functional block-diagram of the defended system
described by \eqref{eq:rounding_defense}--\eqref{eq:defended_closed_loop}
is presented in Fig.~\ref{fig:defended-system}. Compared with the
adversarially perturbed system, the
diagram introduces a rounding block $R$ placed after the noisy signal
function output $\widetilde{s}(k) = \operatorname{sgn}(e(k)) + \epsilon(k)$.
The rounding block maps $\widetilde{s}(k)$ to the defended output
$\hat{s}(k) \in \{-1, 0, +1\}$ according to \eqref{eq:rounding_defense},
recovering the correct signal function value when
$|\epsilon(k)| < \tfrac{1}{2}$. The defended output $\hat{s}(k)$ is then
passed to the amplification block $\beta$ and the remaining control path,
producing the defended control input $\hat{u}(k)$. All remaining blocks
are identical to those of the unperturbed system.
