\subsubsection*{\centering Control Function}

The control $u(k)$ can be determined from \autoref{systemModel} considering
the tracking error by the following control equation \textsubscript{\cite{tymoshchuk2024tracking}}:
\begin{equation}
	u(k) = \begin{cases}
		g(x(k))^{-1} \bigl( -f(x(k)) + \Delta r(k) - \beta \text{sgn}(x(k) - r(k)) \bigr) & \text{if } g(x(k)) \neq 0 \\
		0                                                                                 & \text{if } g(x(k)) = 0
	\end{cases}
	\label{eq:control_function}
\end{equation}
