	For the purpose of finding a solution to the tracking control problem, the control function \control{$k$} has been designed~\textsubscript{\cite{tymoshchuk2024tracking}}:
	\begin{equation}
		u(k) = \begin{cases}
			g(x(k))^{-1} \bigl( -f(x(k)) + \Delta r(k) - \beta \text{sgn}(x(k) - r(k)) \bigr) & \text{if } g(x(k)) \neq 0 \\
			0                                                                                 & \text{if } g(x(k)) = 0
		\end{cases}
		\label{eq:control_function}
	\end{equation}
