\section{C++ Implementation and Performance Comparison}
\label{sec:cpp-implementation}

To verify the simulation results and assess computational efficiency, the
MATLAB reference implementation was ported to C++. The port uses Eigen
matrices for a column-major $2 \times N$ data layout (row~0: state
$x_1$, row~1: state $x_2$), pre-computes the reference difference
matrix $\Delta R$ before the simulation loop, and replaces MATLAB's
conditional signum with a branchless arithmetic template. Gnuplot replaces
MATLAB's native plotting for publication-quality figures.

\subsection{Output Comparison}

The C++ implementation produces state trajectories, control inputs, and
tracking errors that are visually indistinguishable from the MATLAB reference.
Element-wise comparison (see Numerical Validation below) confirms that the
unperturbed outputs agree to machine precision. For the attacked simulation,
because each run draws independent noise samples, exact numerical equivalence
is not expected; however, the qualitative degradation pattern is consistent
across both implementations. Since the graphs are the same, only the C++
outputs are shown in the simulation sections of the main text.

\subsection{Numerical Validation}

Element-wise comparison of the unperturbed outputs yields a maximum
deviation on the order of $10^{-15}$ across all state variables, consistent
with IEEE~754 double-precision machine epsilon of
$2.22 \times 10^{-16}$. The two implementations produce identical
floating-point results up to rounding in the final digits.
