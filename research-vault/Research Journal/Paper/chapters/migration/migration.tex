\section{C++ Implementation and Performance Comparison}
\label{sec:cpp-implementation}

To verify the simulation results and assess computational efficiency, the
MATLAB reference implementation was ported to C++. The port uses Eigen
matrices for a column-major $2 \times N$ data layout (row~0: conversion
$x_1$, row~1: temperature $x_2$), pre-computes the reference difference
matrix $\Delta R$ before the simulation loop, and replaces MATLAB's
conditional signum with a branchless arithmetic template. Gnuplot replaces
MATLAB's native plotting for publication-quality figures.

\subsection{Numerical Validation}

Element-wise comparison of the nominal CSV outputs yields a maximum
deviation of approximately $10^{-15}$ across all state variables, consistent
with IEEE~754 double-precision machine epsilon
($\approx 2.22 \times 10^{-16}$). The two implementations compute identical
floating-point results up to rounding in the final digits.
